# As Primeiras 48 Horas com a Sua Calopsita

Página de vendas 100% mobile-first para o infoproduto "As Primeiras 48 Horas com a Sua Calopsita".

## Características do Projeto
- Design mobile-first otimizado para alta taxa de conexão (connect rate).
- Tipografia responsiva com `clamp()`.
- Paleta de cores suave: Fundo creme/areia, títulos em mostarda queimado/terracota e detalhes em verde sálvia.
- Carrosséis com animação contínua e suave para exibição das folhas do guia e depoimentos.
- Modal de Upgrade Premium com oferta de pacote completo e botão animado com feixe de luz.
- Integração nativa com checkout Lowify e rastreamento WhatsTrack Direct Response Pixel Tracker (Meta Pixel CAPI).
